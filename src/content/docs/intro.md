---
title: What is Kalcite?
---

Kalcite is a compiled programming language and scene engine for games, applications, and future command-line tools. Its source implementation prioritizes explicit costs: no embedded VM, no garbage collector, no hidden allocation, and fixed-capacity game-object pools.

Start with [the overview](../) for current project status, platform support, and the central terminology.

The [Applications and UI roadmap](../roadmap/applications-and-ui/) separates the current static GUI implementation from planned native application capabilities.
