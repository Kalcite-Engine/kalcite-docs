# Design notes

The docs share Kalcite’s soft aquatic/mineral identity without competing with technical content. Cream and graphite are the reading surface; honey-orange marks navigation and links; pale aqua is a quiet supporting tone. Starlight supplies accessible navigation, search, breadcrumbs, table of contents, heading anchors, responsive layout, code copy buttons and theme controls.

Typography is deliberately calm and readable. The small `K` mark is CSS text, not mascot art. Both themes are independently tokenized. Focus visibility, semantic Markdown headings, readable code contrast and reduced motion are required. No Kally art is generated or used.
