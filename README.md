# Kalcite documentation

An independent Astro Starlight documentation site. Content lives in `src/content/docs/` as Markdown and builds for the `/kalcite-docs` GitHub Pages subpath by default.

```sh
npm ci
npm run dev
npm run format
npm run lint
npm run typecheck
npm test
npm run build
```

Set `SITE_BASE=/` for a root-path local preview. Confirm features against Kalcite source before documenting them.
